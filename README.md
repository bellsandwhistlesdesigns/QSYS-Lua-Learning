# Q-SYS Lua Learning

Learning Lua programming and AV device driver development.

## Projects

### AV Control System
A simulated AV control system used to learn:
- Lua tables
- Functions
- Event-driven programming
- State management

### TCP Socket Projector Driver
A simulated projector driver used to learn:
- Driver architecture
- Command parsing
- Device feedback
- State tables
- TCP communication concepts

Future versions will incorporate:
- Q-SYS TcpSocket.New()
- Event Handlers
- Polling
- Auto Reconnect
- Production Driver Design
